# Nexus Tech Lab

Premium, ultra-modern single-page agency portfolio built with **Vite + React + Tailwind CSS**.

## Local development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
4. Preview production build:
   ```bash
   npm run preview
   ```

## Tech stack

- React
- Vite
- Tailwind CSS
- ESLint
